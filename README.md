# 🌍 Tour Website

A responsive and visually appealing tour website built with **HTML** and **CSS** to showcase travel destinations, features, and services.

---

## 📌 Overview

This project is a static tour website template that highlights beautiful travel locations and informational sections. It is designed to be simple, fully responsive, and user-friendly — perfect for showcasing tours or travel packages.

---

## 🖥️ Features

- 🗺️ Clean layout with image sections  
- 📱 Responsive design for desktop and mobile  
- 🎯 Easy navigation and informative content  
- 📂 Simple structure for quick customization

---
